# Умелые ручки

Идеи и пошаговые схемы поделок для занятий с детьми 6–10 лет.

```bash
npm install
npm run dev      # разработка: http://localhost:5173
npm run build    # статическая сборка в dist/ (можно выложить на любой хостинг)
```

## Как устроено

- `src/data/crafts/*.js` — одна поделка в одном файле: материалы, шаги, советы педагогу.
- `src/diagrams/kit.js` — функции для рисования схем (линии сгиба, стрелки, глазки и т.п.).
  Складки оригами считаются геометрически (`reflect`, `intersect`), поэтому клапаны ложатся точно.
- `src/views/PresentView.vue` — режим показа на проекторе: ← → / пробел / PageUp-PageDown, F — весь экран, Esc — выход.

Чтобы добавить поделку, создайте файл в `src/data/crafts/` по образцу и подключите его в `src/data/index.js`.
